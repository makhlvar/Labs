# Лабораторная работа №1: Генерация растровых изображений (Netpbm)

## Описание проекта
Программа на C++17 для генерации растровых графических файлов в текстовых форматах PGM P2 и PPM P3. Проект реализует собственный графический движок с поддержкой базовых примитивов, алгоритмов низкой растеризации, пространственной фильтрации и варианта 2 повышенной сложности, а именно процедурной доски с плитами Трюше.

## Структура проекта

Приложение построено на базе ООП с четким разделением ответственности. Код поделен на структурные блоки.

### Структура файлов и их назначение:

**1. Ядро графики (Core):**
- `include/Color.hpp` / `src/Color.cpp` — структура для хранения RGBA-каналов (нормализованы от 0.0 до 1.0). Реализует интерполяцию (`lerp`), альфа-смешивание (`blend`), перевод в оттенки серого и расчет Евклидова расстояния для заливки.
- `include/Image.hpp` / `src/Image.cpp` — непрерывный двумерный буфер пикселей на базе `std::vector<Color>`. Обеспечивает безопасный доступ к памяти, очистку и сглаживание SSAA.
- `include/Canvas.hpp` / `src/Canvas.cpp` — контекст рисования (обертка над `Image`). Управляет цветом пера, отсечением по границам (Clipping) и сглаживанием.
- `include/IShape.hpp` — абстрактный базовый класс (интерфейс) с чисто виртуальным методом `draw()`.

**2. Геометрические примитивы (Задания 1–3):**
- `include/Rectangle.hpp` / `src/Rectangle.cpp` — прямоугольник (контур и заливка).
- `include/NestedSquares.hpp` / `src/NestedSquares.cpp` — вложенные квадраты с интерполяцией цвета.
- `include/LineSegment.hpp` / `src/LineSegment.cpp` — отрезки (алгоритмы Ву и толстого Брезенхема).
- `include/Polygon.hpp` / `src/Polygon.cpp` — многоугольники.
- `include/FloodFill.hpp` / `src/FloodFill.cpp` — нерекурсивная заливка области на базе `std::queue`.

**3. Экспорт и ввод-вывод:**
- `include/IPNMExporter.hpp` — интерфейс для экспорта.
- `include/PPMExporter.hpp` / `src/PPMExporter.cpp` — экспорт в цветной формат PPM P3.
- `include/PGMExporter.hpp` / `src/PGMExporter.cpp` — экспорт в полутоновой формат PGM P2.

**4. Вариантная часть:**
- `include/Variant.hpp` / `src/Variant.cpp` — реализация Варианта 2 процедурная доска с плитами Трюше.

**5. Точка входа:**
- `src/main.cpp` — главный файл с интерактивным консольным меню, обработкой исключений и вызовом нужных генераторов.

**5. Готовые изображения** 

* `output/` директория, в которую сохраняются сгенерированные изображения:
- line_bresenham.png
- nest.pgm
- rec.png
- rec.ppm
- test.ppm

## Требования

Для сборки и запуска проекта понадобятся:
* Компилятор с поддержкой стандарта C++17/20.
* Система сборки CMake (версии 3.10 и выше) / Make

## Сборка и запуск

### Способ 1: Сборка через CMake (Рекомендуемый)

- Перейдите в корневую папку проекта:
    bash

    cd lab1

- Создайте папку для сборки и перейдите в неё:
    bash

    mkdir build
    cd build

- Сгенерируйте файлы сборки и скомпилируйте проект (с флагами -Wall -Wextra -Werror -pedantic согласно ТЗ):
    bash

    cmake ..
    cmake --build .

- Запустите программу (находясь внутри папки build):
    bash

    ./NetpbmGenerator

    (На Windows файл будет называться NetpbmGenerator.exe).

### Способ 2: Сборка через Makefile
- Перейдите в корневую папку проекта: 
    bash

    cd lab1

- Соберите проект одной командой (Makefile автоматически создаст папку build и скомпилирует все .cpp файлы из src/):
    bash

    make

- Запустите программу (также из папки build):
    bash

    cd build
    ./app

    (На Windows: app.exe).

### Как очистить проект от мусора

Если вы хотите удалить скомпилированные файлы и начать сборку с нуля:

- При использовании CMake: просто удалите папку build (rm -rf build).

- При использовании Makefile: выполните команду make clean.


## Использование

После выполнения программы готовое изображение появится в папке `output/`.
